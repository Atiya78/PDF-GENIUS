PDF Genius website update

All six requested phases were implemented and checked locally. Not published. Website: https://pdfgenius.app.

What changed

  • Phase 1: removed the development banner; searchable noindex 404 with eight tool links and true production 404; shared successful-download Ads tracking; hidden empty social URLs; one footer phone; Support is the contact route; image alternatives, crisp fixed-size logo and reduced decorative overlap.
  • Phase 2: verified-only siteStats config; neutral claims; honest local/server processing and privacy copy; no invented retention, support deadlines, ratings, reviews or usage figures.
  • Phase 3: one homepage uploader; relevant file-type chooser retains original File objects; eight featured tools; requested section order and eight FAQs; free-web/paid-API pricing clarification; skip link, keyboard/focus and mobile navigation.
  • Phase 4: 43 public HTML snapshots (12 marketing/legal pages and 31 tool pages); all 27 requested clean tool URLs plus existing extras reuse lazy tool components; unique metadata, one H1, three steps, four FAQs and related links; route schemas; 31 query-preserving 301s; clean sitemap and private noindex shell.
  • Phase 5: original Tawk widget ID retained; load after interaction or five seconds, one script; mobile spacing, concurrent-processing hide/show, Contact Support opener and failure notification without abandoning a file; protected server-signed identity; guest/file privacy.
  • Phase 6: lazy routes and player/per-tool animation chunks; near-viewport animation loading; public image sizing and below-fold footer logo lazy loading; self-hosted OFL fonts with swap and preload; gzip/brotli negotiation, immutable hashed assets, no-cache HTML; contrast/heading/link-label repairs.

Prerendering approach

Puppeteer runs after Vite and captures the existing React pages. This avoids an SSR rewrite and reuses working tool components. The build fails on missing public content, invalid H1/metadata or forbidden review/rating schema. Third-party trackers/chat are blocked during capture; private pages are excluded. Chrome is located locally or installed into the existing repository cache for Railway builds.

  • Production Express smoke checks passed: redirects, canonical content/tool schema, true404, private noindex, API namespace preservation, 43 unique sitemap URLs, gzip, immutable assets and no-cache HTML.

Risky or unverified items

  • No destructive durable-file retention or account-deletion automation was invented. This requires the owner's policy.
  • Coordinate-sensitive/user-generated PDF/image previews retain their existing computed sizing; arbitrary width/height or aspect ratios were not imposed. Public marketing images have explicit dimensions.
  • No live Google Ads-account, real Tawk provider identity, authenticated account/purchase flow or paid AI conversion validation was claimed.
  • Regional optional-cookie consent requirements/defaults were not invented; existing base Ads config was retained as requested. Separate consent controls are a possible follow-up.
