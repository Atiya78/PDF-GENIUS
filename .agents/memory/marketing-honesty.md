---
name: PDF Genius marketing honesty
description: User-required limits on public claims, metrics, reviews, privacy promises, and support promises.
---

Public PDF Genius copy must not invent statistics, testimonials, reviews, performance guarantees, or support availability. Only publish metrics explicitly verified by the owner. Verify tool execution and actual file retention before making privacy or deletion promises; unknown facts need clearly marked TODOs.

**Why:** the owner runs Google Ads and explicitly cannot substantiate the imported user counts, uptime, security superlatives, and quality guarantees.

**How to apply:** apply this rule to marketing pages, tool landing pages, metadata, structured data, and future copy changes. Do not add Review or AggregateRating structured data without genuine reviews.
